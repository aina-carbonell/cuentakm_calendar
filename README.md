# 🚗 Sistema Automático de Registro de Kilómetros

Automatiza el registro de kilometraje profesional usando Google Calendar, Google Sheets y Google Maps API.

## ✨ Características

- 📅 Lee eventos de Google Calendar automáticamente
- 🗺️ Calcula distancias reales usando Google Maps
- 📊 Genera reportes automáticos en Google Sheets
- 🏢 Considera la oficina como punto de inicio/fin de cada día
- 💰 Calcula costos basados en tarifa por kilómetro
- 🔄 Actualización diaria automática

## 🚀 Inicio Rápido

1. Clona este repositorio
2. Configura las credenciales de Google
3. Ejecuta `npm run setup`
4. ¡Listo! El sistema comenzará a registrar automáticamente

## 📋 Prerrequisitos

- Cuenta de Google Workspace
- Proyecto en Google Cloud Console con APIs habilitadas
- Node.js 14+
